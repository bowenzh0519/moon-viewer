> 从你所在的地点出发，在浏览器中观察此刻或任意时刻的真实月相、月面姿态与月球相关天象。

## 项目简介

“观月”是一款以地点和时间为核心输入的交互式月球可视化应用。它不是一张固定月相图片，而是根据观测者的经纬度、当地时间和时区，在浏览器中实时计算并渲染：

- 月球在天空中的高度、方位与视直径；
- 从当前观测地点看到的月相、天平动和月面位置角；
- 晨昏线、地照、月面地形明暗与月面地标；
- 当地月出、月落和实时方向；
- 月食过程以及月掩亮星、月掩行星事件。

项目提供“简洁”和“专业”两种界面。简洁模式面向快速查看与分享；专业模式保留时间、地点、观测量、月食、月掩星和显示参数等完整控制。页面同时适配桌面和手机浏览器，并支持中文与英文。

## 主要功能

### 真实月面渲染

- 基于 WebGL 的球面月球渲染，而非预制月相序列图；
- 根据太阳、月球与地面观测者的实时几何关系生成受光面；
- 呈现地心光学天平动、地表视差造成的日周变化和月面位置角；
- 支持地照亮度、表面特征对比度、经纬网、晨昏线和地标显示；
- 使用 8K / 16K 分级 WebP 月面切片，按当前视图逐块加载高清纹理；
- 使用 LOLA 高程数据参与月面法线、掠射阴影和月缘细微起伏的表现。

### 地点与时间

- 使用浏览器定位获取当前位置；
- 直接输入 WGS-84 经纬度，或通过高德地图选点；
- 中国大陆地图点选坐标会从 GCJ-02 转换为 WGS-84 后再参与天文计算；
- 根据经纬度识别 IANA 时区，并按所选日期处理夏令时；
- 可关闭自动时区，改用固定 UTC 偏移；
- 支持按 5 分钟、1 小时或 1 天步进，也支持多档正向、反向时间流速。

### 观测信息

专业模式显示以下实时观测量：

- 亮面比例与月相名称；
- 相位角；
- 月球高度与方位；
- 地月距离；
- 经度、纬度天平动；
- 月面位置角。

地图还会显示从观测点出发的月球实时方向、下一次月出方向和下一次月落方向。方位角以正北为 `0°`，顺时针增加。

### 月食预测

- 搜索当地未来可见的月食；
- 区分半影月食、月偏食和月全食；
- 显示 P1、U1、U2、MAX、U3、U4、P4 等接触时刻；
- 标记月球在当地地平线以上的可见区间；
- 支持跳转最佳时刻、拖动时间轴和播放当地可见过程；
- 提供 Danjon 色阶以及可选的 HDR 曝光、绿松石带视觉近似。

月食颜色属于受公开科学资料约束的可调视觉近似，不应被视为对某次月食大气色彩的精确预报。

### 月掩星与月掩行星

- 搜索有限内置目标表中的月掩亮星事件；
- 搜索当地未来月掩行星事件；
- 显示掩始、最接近和掩终状态及时间轴；
- 可跳转至事件并播放前后过程；
- 导出时保留当前有效的月掩目标星点或行星视觉。

月掩搜索采用轻量级浏览器端计算与有限目标表，适合交互演示和初步观测规划，不代替专业星历、IOTA 预报或掩星观测软件。

### 图片导出

- 导出带地点、当地时间、时区和经纬度信息的 PNG；
- 简洁模式始终导出 `1×` 完整月面；若当前处于放大状态，会先平滑回到默认视图；
- 专业模式按当前天文状态导出，并保留月食或月掩目标等有效视觉信息；
- 导出完全在浏览器本地完成，图片不会上传到项目服务器。

## 使用说明

### 简洁模式

1. 打开页面后，应用会以当前时间显示默认地点的真实月面。
2. 点击底部城市可快速切换地点；点击“更多”可使用当前位置或在地图上选点。
3. 桌面端使用滚轮缩放，双击可在默认视图和 `2×` 视图间切换。
4. 手机端在月面区域双指缩放；放大后可单指拖动观察月面细节。
5. 点击“导出”生成完整月面图片。

简洁模式始终跟随真实时间，并有意隐藏复杂参数，适合日常查看、手机浏览和快速分享。

### 专业模式

1. 点击页面右上角“专业”。月面会连续移动、缩放到专业布局，地标和辅助线随后出现。
2. 在“运行模式”中选择：
   - **真实天文模式**：由地点和时间唯一驱动；
   - **自由演示模式**：手动观察天平动、旋转、晨昏线等独立变量。
3. 在“观测地点”中输入经纬度、使用当前位置或在地图选点。
4. 在“观测时间”中选择当地民用时间。自动时区开启时，UTC 由地点对应的 IANA 时区和该日期的夏令时规则换算。
5. 查看“观测信息”，或进入“月食预测”“月掩星预报”面板选择事件并播放。
6. 使用“显示与贴图”调整地照、对比度和辅助标注。

### 精度说明

Astronomy Engine 上游项目将其核心天文位置计算目标描述为与权威模型相比保持约 `±1 arcminute` 的精度，但这不等同于本应用所有输出都具有同一误差范围。最终显示还会受到以下因素影响：

- 输入地点、海拔和系统时间的准确性；
- 大气折射近似，尤其是接近地平线时；
- 时区边界数据的简化；
- 月掩星内置目标坐标和搜索步长；
- WebGL 纹理、地形阴影和视觉增强处理。

本项目适合公众科普、交互探索、摄影构图参考和一般观测规划，不用于航天器导航、测量定标、安全关键决策或要求专业星历精度的工作。

## 隐私与网络请求

当前版本没有用户账户、项目后端数据库或自建分析服务。天文计算和图片导出主要在浏览器本地执行。

使用过程中仍可能产生以下外部请求：

- 从 jsDelivr 加载 Astronomy Engine 与时区库；
- 从高德地图加载地图资源和地图服务；
- 从 GitHub Pages 加载网页与月面切片。

“使用我的位置”只会在用户授权后调用浏览器 Geolocation API。

## 本地运行

项目是静态网站，不需要构建工具。由于高清切片、浏览器安全策略和定位能力的限制，建议通过本地 HTTP 服务预览，而不是直接双击 `index.html`。

```bash
git clone https://github.com/moon-observer/moon-viewer.git
cd moon-viewer
python3 -m http.server 8000
```

随后访问：

```text
http://localhost:8000/
```

建议使用较新的 Safari、Chrome、Edge 或 Firefox，并确保浏览器支持 WebGL、Canvas、ES2020 与 WebP。定位功能通常要求 HTTPS 或 `localhost` 安全上下文。

## 项目结构

```text
moon-viewer/
├── index.html                  # 页面、样式、交互与主要渲染逻辑
├── favicon.svg                # 网站图标
├── nasa_lola_height_4k.js     # 浏览器可加载的 LOLA 高程数据
├── moon_tiles_v3/
│   ├── manifest.js            # 浏览器端切片清单
│   ├── manifest.json          # 切片元数据
│   ├── 8192/                  # 8K 月面 WebP 切片
│   └── 16384/                 # 16K 月面 WebP 切片
├── README.md
└── LICENSE
```

高清月面采用按需加载，而不是一次性解码完整 16K 图片，以降低首屏内存压力。放大月面时，应用根据当前视野逐步请求更高分辨率切片。

## 开发与发布

当前工作流以本地 `moon_observer_v3.html` 为开发版本，以本仓库的 `index.html` 为 GitHub Pages 发布版本。功能应先在本地完成并通过桌面、手机比例测试，再同步到发布仓库。

```bash
cp ../moon_observer_v3.html index.html
rm -rf moon_tiles_v3
cp -R ../moon_tiles_v3 ./moon_tiles_v3

git add -- index.html moon_tiles_v3
git commit -m "Update moon viewer"
git push origin main
```

发布前建议至少检查：

- 简洁/专业模式双向过渡；
- 手机端双指缩放、拖动和吸顶月面；
- 地点、时区和夏令时换算；
- 月食与月掩事件跳转、播放和导出；
- 8K / 16K 切片请求是否返回成功；
- 浏览器标签页名称与中英文界面；
- Safari、Chrome/Edge 以及至少一台真实手机。
